# ZENO

نسخهٔ مستقل مبتنی بر Foxhole VPN با همان رابط و هستهٔ اتصال، برای اندروید، Android TV، ویندوز، مک و لینوکس.

## امکانات

- ورود با حساب Mozilla و انتخاب موقعیت سرور
- اتصال سراسری TUN و پروکسی SOCKS5/HTTP
- مسیریابی تفکیکی سایت‌ها و برنامه‌ها؛ اتصال مستقیم سایت‌های ایرانی
- نمایش مصرف، محافظ تبلیغات و ردیاب، اشتراک اتصال و Smart DNS
- رابط فارسی و راست‌به‌چپ؛ پشتیبانی از تلویزیون اندرویدی
- به‌روزرسانی مستقل از مخزن sahandse/ZENO

این برنامه غیررسمی است. دسترسی سرورها، سهمیه و ورود به حساب تابع سرویس Mozilla و شرایط شبکه است.

## توسعه

```sh

npm test
cd gui
npm ci

```

راهنمای جزئی امکانات در [راهنمای استفاده](docs/UPSTREAM-USAGE.md) و منشأ کد در [UPSTREAM.md](UPSTREAM.md) قرار دارد.

## ساخت اندروید

از بخش Actions، گردش‌کار **Android candidate** را اجرا کنید. خروجی آن APK آزمایشی است و برای انتشار فروشگاهی نیست.
برای ساخت نسخهٔ انتشار، کلید مستقل ZENO و متغیرهای ZENO_KEYSTORE، ZENO_KEYSTORE_PASSWORD و ZENO_KEY_ALIAS لازم است.
گردش‌کار Release با تگ نسخه اجرا می‌شود و فقط پیش‌نویس انتشار می‌سازد.
هنوز آزمون اتصال روی دستگاه واقعی و انتشار عمومی تأیید نشده است.
